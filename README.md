# GlassTube

[![Build IPA](https://github.com/senkuboy0-cyber/GlassTube/actions/workflows/build-ipa.yml/badge.svg)](https://github.com/senkuboy0-cyber/GlassTube/actions/workflows/build-ipa.yml)
[![License: GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)

**GlassTube** is an iPhone YouTube client built with SwiftUI and a
liquid-glass design system — real spring physics, momentum-aware gestures,
fluid animated backgrounds and a code-drawn logo. Video data flows through
the **InnerTubeX** (`innertubex`) API surface, the Kotlin Multiplatform
InnerTube client used by Metrolist and friends.

A GitHub Actions workflow builds an **unsigned IPA** on every push to
`main` — download it from the *Actions* tab under artifacts.

---

## Features

### UI / UX
- **Liquid glass everywhere** — layered `Material` panels with specular
  sheen, inner light borders and tint bleed (`Glass.swift`).
- **Fluid animated background** — sine-motion gradient blobs on a 30 Hz
  timeline behind every screen (`FluidBackground.swift`).
- **Floating glass tab bar** — matched-geometry selection pill, bouncing
  SF Symbols, haptics on every switch.
- **Splash screen** — code-drawn logo springs in, per-letter wordmark
  stagger, drag parallax with momentum reset, physics-driven loading dots.
- **Code-drawn app logo & icon** — the SwiftUI mark (`GlassTubeLogo.swift`)
  and a Python/PIL generator for the 1024 px App Store icon
  (`Scripts/make_appicon.py`). No binary assets in the repo.

### Motion
- **Spring presets** — snappy / bouncy / gentle / opulent, used
  consistently across the app (`Spring.swift`).
- **Real spring physics** — an analytic damped-harmonic-oscillator solver
  renders the splash dots at 60 Hz from actual mass-spring-damper math.
- **Inertia & momentum** — gestures project release velocity into a settle
  target (`SpringPhysics.momentumTarget`): fling the mini player up to
  expand, drag the player down to dismiss, scrubber flings extend the seek.
- **Rubber band** — iOS-style overscroll resistance on stretchy headers.
- **Staggered entrances** — feed cards, search results and library rows
  spring in with per-index delays.
- **Player** — glass transport controls, velocity-aware scrubber,
  double-tap ±10 s with spring-flash icons, auto-hiding overlay,
  background audio (`UIBackgroundModes: audio`) and Now Playing info.

### YouTube engine
- Mirrors **innertubex v0.13.1**: same endpoint paths
  (`/youtubei/v1/{search,browse,player,music/get_search_suggestions}`),
  same client profiles (`WEB 2.20260708.00.00`, `IOS 21.26.4`,
  `ANDROID_VR 1.65.10`, `WEB_REMIX 1.20260707.12.00`), same header
  contract (`X-YouTube-Client-Name/Version`, `Origin`, `X-Origin`,
  `Referer`, `Accept-Language`, UA) and the same
  `IOS → ANDROID_VR → WEB` player fallback chain.
- Defensive response parsing — renderer trees are discovered by walking
  the JSON (`videoRenderer`, `gridVideoRenderer`, `compactVideoRenderer`,
  `lockupViewModel`), so feeds survive layout changes.
- Playback prefers **HLS manifests** (native AVPlayer support) with an
  MP4 progressive fallback.

```
GlassTube/
├── project.yml                     # xcodegen spec (generates the .xcodeproj)

│   │   ├── Search/                 # suggestions, chips, results
│   │   ├── Library/                # watch later, history, settings
│   │   └── Player/                 # full player + mini player
│   ├── Networking/                 # innertubex-mirrored InnerTube engine
│   ├── Models/
│   ├── Support/Info.plist
│   └── Assets.xcassets/            # icon PNG is generated by CI

    ├── build-ipa.yml               # builds the unsigned IPA artifact
```

## Build locally

Requirements: **macOS 14+**, **Xcode 16+**, [xcodegen](https://github.com/yonaskolb/XcodeGen),
Python 3 with Pillow (only for the icon).

```bash
brew install xcodegen
python3 Scripts/make_appicon.py     # generates AppIcon1024.png
xcodegen generate                   # creates GlassTube.xcodeproj
open GlassTube.xcodeproj            # select a simulator, Cmd+R
```

## Get the IPA from CI

1. Push to `main` (or run the **Build IPA** workflow manually from the
   *Actions* tab).
2. Open the finished run and download **GlassTube-unsigned-ipa**.

The IPA is **unsigned** — sign it before installing:

| Tool | Notes |
| --- | --- |
| [Sideloadly](https://sideloadly.io) | Free Apple ID, 7-day resign |
| [AltStore](https://altstore.io) | Free Apple ID, auto-resign |
| Xcode Organizer | Your own provisioning profile |
| Paid developer account | Distribute via Ad Hoc / TestFlight |

## Linking the original innertubex framework (optional)

The default engine is a pure-Swift port of the innertubex API surface. To
link the actual Kotlin Multiplatform framework, run the
**Build InnerTubeX iOS framework** workflow (produces `InnerTubeX.xcframework`)
and follow [KotlinBridge/README.md](KotlinBridge/README.md).
